# Changelog

## v0.1.0 (2026-03-17)

Initial release with 12 reusable skills for Claude Code.

### Skills Included

**Meta / Tooling:**
- **skill-builder** - Create, test, evaluate, and optimize Claude Code skills
- **headless-runner** - Run Claude Code programmatically for CI/CD and automation
- **cloud-setup** - Set up development environments in cloud sessions

**Code Quality:**
- **codebase-organizer** - Monitor file sizes and split large files
- **test-coverage-guardian** - Analyze test coverage and enforce quality gates
- **perf-reviewer** - Performance review and benchmarking

**Project Management:**
- **sprint-planner** - Sprint planning from design docs with velocity analysis
- **sprint-executor** - Sprint execution with TDD and milestone tracking
- **design-doc-creator** - Structured design document creation
- **release-manager** - Automated release workflows

**Collaboration:**
- **github-issue-triage** - Issue triage against design docs
- **agent-inbox** - Cross-agent messaging patterns
